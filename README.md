# Miira Web Portfolio

Este es un portafolio personal desarrollado con Next.js, Tailwind CSS, y otras tecnologías modernas del frontend.

## Características

- Diseño inspirado en la escuela Bauhaus
- Modo oscuro/claro
- Animaciones con Framer Motion
- Componentes totalmente responsivos
- Navegación suave entre secciones
